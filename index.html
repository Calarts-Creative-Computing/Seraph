What’s Inside

  • Seraph PCB design – A hardware platform for connecting various sensors and controls.
  • Demo code – Examples showing how to interface different sensors with the Seraph PCB.
  • Customization support – A flexible base for custom MIDI and interactive art projects.

Quick Start

  1. Solder your Teensy to headers so it can be removed and reused later.
  2. Install required Arduino libraries (most demos use the Teensy USBMIDI library).
  3. Set Teensy board mode to Serial + MIDI in the Arduino IDE.
  4. Upload a demo and start experimenting with interactive MIDI control.

Tutorial Highlights

  • Analog sensor wiring without pulldown resistor (e.g., potentiometer)
  • Analog sensor wiring with pulldown resistor (e.g., LDR, FSR)
  • Digital input wiring (e.g., buttons)
  • I²C sensor wiring (SDA/SCL + power/ground)
