01 — Board Overview & Hardware Setup

Seraph is a breakout board for the Teensy 4.1 that simplifies wiring, power regulation, and I/O routing so you can focus on instrument and installation design.

What's on the Board

First-Time Setup

Step 1 — Install Arduino IDE & Teensyduino

  1. Download Arduino IDE from arduino.cc/en/software.
  2. Download Teensyduino from pjrc.com/teensy/teensyduino.html.
  3. Run Teensyduino installer and let it detect your Arduino IDE.
  4. Verify Teensy boards appear in Tools > Board > Teensyduino.

Step 2 — Mount the Teensy on Seraph

  • Use header pins (do not solder Teensy directly to the board).
  • Seat Teensy 4.1 in the socket with USB facing the board edge.
  • Verify all pins are aligned and fully seated.

Step 3 — Configure USB-MIDI Mode

  1. Select Tools > Board > Teensy 4.1.
  2. Select Tools > USB Type > Serial + MIDI.
  3. Connect over USB and verify serial + MIDI device visibility.

02 — First Wiring Tutorial: Button & LED

Build your first test circuit: button press drives LED output and sends MIDI Note On/Off events.

What You'll Need

Seraph + Teensy 4.1
Mounted and powered.
1x momentary push button
Digital input trigger.
1x LED + 470Ω resistor
Visual output indicator.
Jumper wires
For signal and ground routing.

Wiring Diagram

Digital channel strips provide +, −, and S pins.

  • Buttons use S + −.
  • LEDs use S + − with current-limiting resistor.

The Code

const int BUTTON_PIN = 1;
const int LED_PIN = 2;
const int MIDI_CHANNEL = 1;
const int MIDI_NOTE = 60;
const int MIDI_VELOCITY = 100;
int lastButtonState = HIGH;

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int buttonState = digitalRead(BUTTON_PIN);

  if (buttonState == LOW && lastButtonState == HIGH) {
    digitalWrite(LED_PIN, HIGH);
    usbMIDI.sendNoteOn(MIDI_NOTE, MIDI_VELOCITY, MIDI_CHANNEL);
  }

  if (buttonState == HIGH && lastButtonState == LOW) {
    digitalWrite(LED_PIN, LOW);
    usbMIDI.sendNoteOff(MIDI_NOTE, 0, MIDI_CHANNEL);
  }

  lastButtonState = buttonState;
  while (usbMIDI.read()) {}
}

INPUT_PULLUP

Internal pullup keeps input HIGH by default and reads LOW on button press, removing need for an external resistor for simple buttons.

Event-Based MIDI

Transmit only on state transitions to avoid MIDI flooding and preserve timing stability.

usbMIDI.read()

Always flush USB MIDI at loop end with while (usbMIDI.read()) {} to maintain connection stability.

Testing

  1. Set USB Type to Serial + MIDI.
  2. Upload sketch.
  3. Open MIDI monitor (MIDI Monitor or MIDI-OX).
  4. Confirm LED response and Note On/Off output.

03 — Analog Sensors: Potentiometers & FSRs

Analog channels convert variable voltages into usable data for expressive MIDI control.

3A — Potentiometer (No Pulldown Required)

Potentiometers use power, ground, and signal; map 0–1023 analog values to 0–127 MIDI CC values and send only changed values.

int rawValue = analogRead(A1);
int ccValue = map(rawValue, 0, 1023, 0, 127);
if (ccValue != lastCCValue) {
  usbMIDI.sendControlChange(74, ccValue, 1);
}

3B — FSR / LDR (Pulldown Resistor Required)

Why a Pulldown Resistor?

FSRs/LDRs are variable resistors; use a fixed pulldown resistor to form a voltage divider so the analog pin reads a stable voltage.

Wiring Diagram

Recommended Resistor Values

  • Start with 10kΩ for FSR/LDR channels.
  • Tune resistor value based on sensor sensitivity and target dynamic range.

Code

const int FSR_MIN = 50;
const int FSR_MAX = 900;
int rawValue = analogRead(A2);
int ccValue = map(constrain(rawValue, FSR_MIN, FSR_MAX), FSR_MIN, FSR_MAX, 0, 127);
usbMIDI.sendControlChange(11, ccValue, 1);

04 — I²C Devices: IMUs, Displays & More

I²C lets multiple devices share SDA and SCL lines; Seraph provides I²C blocks A/B/C on the same I²C0 bus.

Common I²C Devices for NIME Projects

MPU-6050 / BNO055
Motion and gesture control.
SSD1306 OLED
Parameter and status display.
ADS1115
Additional high-res analog inputs.
VL53L0X
Distance sensing.
TCS34725
Color sensing for interactive systems.

Wiring

I²C sensor wiring reference (pins, suggested wire colors, and Seraph header mapping)
Component PinWire ColorSeraph Header

The pin/function labels are the primary reference; wire colors are suggested only and can be replaced with any clear labeling scheme.

Using Multiple I²C Devices

  • All blocks share one bus, so each device needs a unique address.
  • For dual MPU-6050, choose either one of the two sensors and set its ADDR pin high (tie ADDR to 3.3V/VCC) to shift that device from 0x68 to 0x69.
  • Mixed device types generally work with default addresses.

Code Example: MPU-6050 IMU to MIDI Pitch Bend

#include "Wire.h"
#include "Adafruit_MPU6050.h"
Adafruit_MPU6050 mpu;

void setup() {
  Wire.begin();
  mpu.begin();
  mpu.setAccelerometerRange(MPU6050_RANGE_2_G);
  mpu.setGyroRange(MPU6050_RANGE_250_DEG);
}

void loop() {
  sensors_event_t accel, gyro, temp;
  mpu.getEvent(&accel, &gyro, &temp);
  int pitchBend = map(constrain(accel.acceleration.x * 100, -1000, 1000), -1000, 1000, -8192, 8191);
  usbMIDI.sendPitchBend(pitchBend, 1);
  delay(10);
  while (usbMIDI.read()) {}
}

Troubleshooting I²C

  • Check sensor power and shared ground.
  • Verify address conflicts and required pullups for your module.
  • Confirm libraries are installed and bus initialized with Wire.begin().

05 — MIDI Mapping in Code

Use Teensyduino USB-MIDI primitives to map sensors to musical control behavior.

Core MIDI Message Types

Note On/Off
Trigger and release note events.
Control Change
Continuous parameter control (0–127).
Pitch Bend
Signed bend range: −8192 to +8191.
Program Change
Patch switching per channel.

usbMIDI Cheat Sheet

usbMIDI.sendNoteOn(note, velocity, channel);
usbMIDI.sendNoteOff(note, 0, channel);
usbMIDI.sendControlChange(ccNumber, value, channel);
usbMIDI.sendPitchBend(value, channel);
usbMIDI.sendProgramChange(program, channel);
while (usbMIDI.read()) {}

Useful MIDI CC Numbers

  • CC 1: Mod Wheel
  • CC 7: Volume
  • CC 10: Pan
  • CC 11: Expression
  • CC 74: Filter Cutoff

06 — Connecting to a DAW

Route Seraph MIDI into Ableton, Max/MSP, and any DAW supporting USB MIDI input.

6A — Ableton Live

Enable MIDI Input

  1. Open Preferences and go to Link / Tempo / MIDI.
  2. Enable Track for Teensy MIDI input.
  3. Enable Remote when mapping controls.

Mapping CC to a Parameter

  1. Enter MIDI Map Mode (Cmd/Ctrl + M).
  2. Select parameter and move Seraph control.
  3. Exit map mode and fine-tune min/max ranges.

Triggering Clips with Buttons

  1. Enter MIDI Map Mode.
  2. Select clip slot and press Seraph button.
  3. Exit map mode.

6B — Max/MSP

Default Seraph sketches use USB MIDI; some advanced projects use serial streams that require manual parsing with Max's serial object.

Common DAW Issues

  • Device missing: verify Serial + MIDI and re-upload.
  • Stuck notes: ensure every Note On has matching Note Off.
  • Noisy CC: apply smoothing and tune resistor/sensor setup.
  • Channel mismatch: align DAW channel input with sketch output channel.

Adding Smoothing to Reduce Jitter

float smoothed = 0;
const float ALPHA = 0.1;

void loop() {
  float raw = analogRead(A1);
  smoothed = ALPHA * raw + (1.0 - ALPHA) * smoothed;
  int ccValue = map((int)smoothed, 0, 1023, 0, 127);
  while (usbMIDI.read()) {}
}
