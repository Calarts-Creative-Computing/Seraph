First-Time Setup

  1. Install Arduino IDE and Teensyduino.
  2. Mount Teensy 4.1 to Seraph using headers.
  3. Set Tools → USB Type → Serial + MIDI.
  4. Upload a demo sketch and verify MIDI connectivity in your system.

MIDI + DAW Integration Highlights

  • Core messages: Note On/Off, Control Change, Pitch Bend, Program Change.
  • Use event-based transmission and simple filtering to avoid MIDI flooding.
  • Ableton, Max/MSP, Logic, Bitwig, Reaper, Pure Data, and SuperCollider workflows are covered in the README guide.
  • For stable operation, keep while (usbMIDI.read()) {} at the end of your loop.
